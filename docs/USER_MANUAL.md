# DermaCare Clinic Management — User Manual

## 1. Signing In
- Launch **DermaCare Clinic** from the Desktop or Start Menu.
- Default administrator credentials (change immediately after first login):
  - **Username**: `admin`
  - **Password**: `Admin@123`

## 2. Keyboard Shortcuts
- **F2**: Quick-open **New Patient** registration form.
- **F3**: Quick-open **Book Appointment** form.

## 3. Daily Workflow
1. **Patients**: Register new patients, search by name/code/phone, or open a patient's profile to view visit, EMR, and billing history.
2. **Doctors**: Link doctor user accounts and configure weekly availability slots.
3. **Appointments**: Book scheduled or walk-in visits, filter by date/doctor, and move visits through *Scheduled → Confirmed → In Progress → Completed*.
4. **Consultations & EMR**: Select an *In Progress* or *Completed* appointment and click **Open Consultation** to record diagnosis, ICD-10 code, prescriptions, and export a PDF prescription.
5. **Billing**: Issue invoices from the clinic service catalog, record Cash/Card/Insurance payments, and export PDF invoices.
6. **Reports & Settings (Admin)**: View appointment/revenue summaries, export Excel reports, manage users/services, and run SQL Server backups.
